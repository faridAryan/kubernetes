# Lab: Explore a Kubernetes Cluster

Use kubectl to get to know a running 3-node cluster.

## Tasks

1. Check the client and server version.
2. List the nodes and their roles.
3. List all namespaces.
4. List the Pods in **every** namespace and spot the control plane components.
5. Show the cluster endpoint information.
6. Describe the node `worker-1`.

When you think you're done, click **Validate**.
